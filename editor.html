Publishing
  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Only this repo. Permission Contents: Read and write. Set an expiry date.
  3. Paste the token below and choose a long editor password (12+ characters).

Stored in the repo, encrypted with the editor password. Forgot it? Delete data/editor-key.enc.json on GitHub and set up again.

Backup

The encrypted file is safe to upload to data/ on GitHub. The plain JSON is not encrypted: keep it on your computer and never upload it.
