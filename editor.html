How to publish your changes
  1. Edit the fields below. Use Preview in booth to check them (only you see the preview).
  2. Click Download encrypted file. You get booth-data.enc.json.
  3. On GitHub, open the repo folder data/ → Add file → Upload files. Upload the file (it replaces the old one) and click Commit changes.
  4. Wait 1–2 minutes. GitHub Pages then shows the new data.

Do not upload the plain JSON backup to GitHub. The repo is public.
