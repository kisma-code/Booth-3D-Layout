How to publish your changes

Edit the fields below, check them with Preview in booth, then click Save & publish. The booth shows the change after 1–2 minutes.

  1. Edit the fields below. Use Preview in booth to check them (only you see the preview).
  2. Click Download encrypted file. You get booth-data.enc.json.
  3. On GitHub, open the repo folder data/ → Add file → Upload files. Upload the file (it replaces the old one) and click Commit changes.
  4. Wait 1–2 minutes. GitHub Pages then shows the new data.

Do not upload the plain JSON backup to GitHub. The repo is public.

Visitor password

The password visitors type to open the booth. Leave empty to keep it. If you change it, tell your colleagues the new one.

Publishing setup (admin) –
  1. On GitHub, open Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → this booth repo. Permissions: Contents: Read and write. Set an expiry date.
  3. Copy the token and paste it below. Choose a long editor password (12+ characters, for example 4 random words).

The token and the visitor password are stored in the repo encrypted with the editor password. Only the editor password can open them. If you forget the editor password, delete data/editor-key.enc.json on GitHub and do this setup again.
